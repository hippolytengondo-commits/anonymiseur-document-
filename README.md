# Anonymiseur de documents

Application web 100 % locale : elle remplace les noms, entités et données identifiantes d'un document (PDF, Word, texte) par des désignations neutres (Société A, Personne B…), puis permet de restaurer les noms d'origine.

- Aucune donnée n'est envoyée en ligne : le traitement s'effectue dans le navigateur.
- Ce dépôt ne contient que le programme. N'y déposez jamais de document réel ni de table de correspondance.

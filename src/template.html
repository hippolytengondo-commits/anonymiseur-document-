Limites et bonnes pratiques

    

  • La détection automatique n'est pas infaillible : relisez toujours le résultat avant tout dépôt.
    • 

  • Les PDF doivent contenir du texte sélectionnable : un PDF numérisé (simple image) n'est pas lisible sans reconnaissance de caractères (OCR). Le texte des images n'est pas traité.
    • 

  • Un PDF anonymisé est régénéré à partir du texte : la mise en page d'origine n'est pas conservée (la version Word est aussi proposée).
    • 

  • Des éléments indirects (montant, lieu, description d'un projet) peuvent permettre une réidentification.
    • 

  • Cette page ne conserve rien : fermer l'onglet efface toutes les données chargées.
